**# 🚗 자동차 경주

## 🚀 구현할 기능 목록

* [✅] "경주할 자동차 이름을 입력하세요." 문구 출력 및 쉼표(`,`)로 구분된 이름 입력 받기
* [] "시도할 횟수는 몇 회인가요?" 문구 출력 및 횟수 입력 받기
* [ ] 자동차 이름 유효성 검사 (5자 이하)
* [ ] 시도할 횟수 유효성 검사 (숫자)
* [ ] 유효하지 않은 입력 시 `IllegalArgumentException` 발생
* [ ] 입력된 이름으로 자동차 생성
* [ ] 시도할 횟수만큼 경주 라운드 반복
* [ ] 각 자동차별로 4 이상일 경우 전진
* [ ] 각 라운드별 실행 결과 출력 (예: `pobi : --`)
* [ ] 최종 우승자 판별
* [ ] 최종 우승자 출력 (단독/공동 형식)
